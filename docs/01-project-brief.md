## 2. リニューアルの目的

現行サイト（ホーム/ギャラリー/会社概要/問い合わせのみの静的サイト）を、
**「会社の信頼と物語を伝えるコーポレートサイト」と「購入できるECサイト」を1つに統合したサイト**へ刷新する。

### ゴール
1. **ブランド価値の言語化・視覚化** — 瀬戸焼×レース人形の希少性・職人の手仕事を伝え、価格に納得感を持たせる
2. **EC売上の立ち上げ** — 見て終わりのギャラリーサイトから「買えるサイト」へ
3. **BtoB信頼の維持** — 卸・法人取引先が見ても信頼できる会社情報の充実

## 4. 要件（ユーザー指定）

1. **ヒーローは動画・画像の両方を設定可能に**
   - Shopify テーマ設定（section schema）で「動画 / 画像」を切替
   - 動画: MP4 自動再生・ループ・ミュート。画像フォールバック必須（モバイル回線・読込失敗時）
2. **コーポレート部分は会社説明を重視**
   - 歴史・製造工程・職人の手仕事をトップページで語る
   - EC への導線をコーポレートコンテンツ内に自然に配置（工程紹介→「この技術で作られた商品を見る」等）
3. **EC部分は購入しやすい導線 + 売り出したい商品を目立たせる**
   - ピックアップ商品（featured collection）をトップ・商品一覧の両方で最上位に
   - カテゴリ導線を明確に（6カテゴリ）
   - カート・購入ボタンは常に視認できる位置に

## 購入テスト

注文完了・Shopify管理画面への登録・注文確認メールの受信まで確認済みです。実際の請求・発送は行っていません。

日本語の本文は通常の商品・記事画面、英語訳は公式 Translate & Adapt で編集します。手順は [コンテンツ管理ガイド](09-content-management.md#商品お知らせの日本語と英語を編集する) を参照してください。

1. サイトのオンラインショップからテスト商品を選び、「テスト購入へ進む」を押します。
2. Shopify のチェックアウトでテストモードの表示を確認します。
3. 確認メールを受け取れるご自身のメールアドレスと、テスト用の配送先を入力します。
4. カード名義は `Test payment gateway`、番号は成功 `1` / 拒否 `2` / ゲートウェイエラー `3`、有効期限は未来の年月、セキュリティコードは `111`。実際のカード番号は使いません。
5. 注文を確定すると Shopify の注文管理と通知メールを確認できます。

国内配送には既存の通常配送870円・速達3,762円の設定を使用します。これらもデモ設定で、実際の運用送料ではありません。
ストアパスワードを求められる場合は Shopify の「オンラインストア → 各種設定」で確認してください。パスワードは公開サイトやリポジトリに記載しません。

公式手順：<https://help.shopify.com/en/partners/manage-clients-stores/test-orders>

## テストを終了するとき

先に `assets/storefront-config.js` の `testCheckoutEnabled` を `false` にしてデプロイし、テスト商品を下書き・テスト記事を非公開にします。その後で Shopify のテスト決済を無効にします。
実販売の開始にはクライアントへの移行・プラン・実際の決済・送料・商品価格などを別途設定します。現在の `checkoutEnabled` は `false` のままです。
フロント側のスイッチは決済モードを変更しません。Shopify 側のテスト決済設定と必ず併用してください。

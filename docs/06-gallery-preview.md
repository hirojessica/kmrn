# 2026-09-05 — 作品写真を主役にしたリニューアル

この文書の方針が docs/01〜05 の旧動画ヒーロー仕様より優先します。

## 変更したこと

- 採用された1枚目のデザイン案を基準に、白磁色の余白・明朝のコピー・大きな作品写真を左右に配置。
- ヒーローを静止画に変更。購入ボタンと新商品へのリンクを設置。
- ヒーロー直下に新商品欄、作品細部、カテゴリ、写真ギャラリー、工房紹介を配置。
- 実物の形を誤って伝えないよう、AI画像の人形ではなく現行サイトにある実物写真を使用。写真の出典とハッシュは asset-sources.json。
- ギャラリープレビューは写真拡大、分類、Escapeで閉じる操作に対応。
- 静的プレビューのJP/EN切替と選択保持を継続。
- 新しい寸法・余白・色は assets/tokens.css に定義。新レイアウトのCSSは gallery-design.css。

## Shopifyとの接続

`theme/` は Shopify公式Dawnのコードを基にした未公開プレビュー用テーマです。
ホーム・ヘッダー・フッターは KM セクション、商品一覧・商品詳細・カート・検索は Dawn の標準テンプレートを利用します。
既存のRiseテーマは保持します。

- `KM new-arrivals`：管理画面でコレクションを選択すると、最大4点の画像・品名・価格・販売状態を参照。未選択なら全商品コレクションを使用。
- 商品ゼロ件の場合は既存作品写真と「オンライン販売の準備中」を表示。架空の価格・在庫・新発売日を設定しません。
- `KM カテゴリ`：カテゴリごとにShopifyのコレクションを選択可能。未指定なら全商品一覧へ。
- `KM 作品ギャラリー`：「作品写真」ブロックで画像・説明を登録、ドラッグで並び替え、関連商品を任意指定。最大24件。
- 画像ブロックを登録するまで既存作品写真を表示。設定で参考写真を非表示にできます。
- `KM hero`：画像選択でヒーロー差し替え。
- 独自セクションの日本語・英語はShopifyのロケールファイルを利用。追加言語では当面英語へフォールバック。
- 商品・カテゴリ・ギャラリーはShopify側で管理。GitHub Pagesはデザイン確認用で、自動同期されません。

## ギャラリー運用の判断

当初検討したメタオブジェクト方式は、数多くの作品や独立した一覧ページが必要になった段階での拡張候補です。
今回のプレビューには、写真を手軽に登録できるテーマ標準の画像ブロック方式を実装しました。
写真ファイルをアップロードするだけではなく、ギャラリーの画像ブロックへ割り当てて保存します。

## 今後の本番準備

- 正式な商品名・価格・在庫・送料・返品条件を登録。
- コレクションを作成して各セクションへ指定。
- ストアの日本語・英語公開設定と商品翻訳を調整。
- Shopifyの会社案内やお知らせの移植。現在のテーマの会社紹介導線はホームの工房紹介へ。
- 本番用の作品撮影・ヒーロー素材選定。現状は現行サイトの工房背景を含む実物写真。
- 決済、配送、税、法定表示、ドメイン、クライアントへの所有権移転を別途実施。
- 実商品で購入・カート・在庫変動の確認。
- 本番公開時に `KM プレビュー → 検索エンジンに掲載しない` をオフにする。

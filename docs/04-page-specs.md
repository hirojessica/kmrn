# 04. ページ別仕様

> レイアウトの正は `mockups/` の各HTML。本書は構造・挙動・コンテンツ要件の定義。

## 4.0 共通の言語対応

- 全6ページの表示文言・ページタイトル・ARIAラベルを日本語/英語で切り替える
- ヘッダーに常時表示する `JP / EN` で手動切り替えでき、選択値はページ遷移後も保持する
- 保存された選択がない初回アクセスのみ、ブラウザの優先言語が日本語ならJP、それ以外はENを表示する
- 静的モックでは `mockups/assets/language.js` の辞書で再現し、Shopify本番ではロケールファイルと翻訳機能へ移植する

## 4.1 トップページ（mockups/index.html）

### S1. ヒーロー `s-hero`
- 高さ: `min(88vh, 820px)`、フルワイド
- **メディアは「動画 / 画像」切替可能**（Shopify section 設定。schema は docs/05 参照）
  - 動画: MP4, autoplay / muted / loop / playsinline。`poster` に画像を必ず設定
  - `prefers-reduced-motion: reduce` 時は動画を再生せず poster 画像を表示
  - 画像モード: 1920×1080 推奨、object-fit: cover
- オーバーレイ: ink を透過（デフォルト 35%、設定で 0–60% 可変）
- テキスト（左下寄せ・白）:
  - 英字ラベル "SINCE 1951 — SETO, AICHI"
  - コピー（serif・fs-hero）: 「千年の陶土に、レースを咲かせる。」
  - サブコピー: 「瀬戸焼の技で生まれる陶製レース人形。KM名古屋ドールの手仕事をお届けします。」
  - CTA 2つ: `c-btn--primary`「オンラインショップ」 / `c-btn--ghost-inv`「私たちについて」
- スクロールサイン（縦線+ "Scroll"）を中央下部に

### S2. ピックアップ商品 `s-pickup`（背景: porcelain）
- 見出し: ラベル "PICK UP" + 「おすすめの商品」+ 右端に「すべての商品を見る →」(c-textlink)
- 商品カード4点（コレクション `featured` から。件数は 2–8 で設定可変）
- 1点目のカードに `c-badge--pickup`「PICK UP」バッジ例を表示
- カード: 正方形画像 / 商品名(serif h3) / カテゴリ名(sm, ink-soft) / 価格(税込表記)

### S3. 私たちについて `s-about`（背景: white）
- 2カラム（PC: 画像45% + テキスト55%、SP: 縦積み・画像先）
- 画像: 工房・職人の手元写真
- テキスト: ラベル "ABOUT US" + 見出し「瀬戸の土と、七十年。」+ 本文3-4行
  （昭和26年創業 / 輸出向け陶磁器人形 / 瀬戸焼の技術継承、を必ず含む）
- CTA: `c-btn--ghost`「会社案内を見る」 + `c-textlink`「オンラインショップへ →」

### S4. 製造工程 `s-process`（背景: celadon-light）
- 見出し: ラベル "OUR CRAFT" + 「手仕事の工程」
- 7工程を代表4ステップに集約したカード横並び（PC4列/SP2列）:
  1. 原型・型づくり / 2. 鋳込み成形 / 3. 施釉・本焼成（1300℃・24時間） / 4. 上絵付け・上絵焼成
- 各カード: 番号（font-en・gold・大きく）+ 工程名(serif) + 説明2行 + 写真
- 末尾中央 CTA: `c-btn--primary`「この手仕事から生まれた商品を見る」→ /collections/lace-doll

### S5. カテゴリから探す `s-category`（背景: porcelain）
- 見出し: ラベル "CATEGORY" + 「カテゴリから探す」
- 6カテゴリカード（PC3列×2段/SP2列）: 陶製レース人形 / カントリー雑貨 / アロマポット / 招福アイテム / モールド・型 / 資材
- カード: 横長写真 + カテゴリ名(serif) + 英字名(label) + hover で画像 zoom + 「→」表示

### S6. お知らせ `s-news`（背景: white）
- 見出し: ラベル "NEWS" + 「お知らせ」+ 右端「一覧へ →」
- 最新3件をリスト形式（日付 sans / カテゴリバッジ / タイトル）。罫線区切り

### S7. フルワイドCTA `s-cta`（背景: ink 上に工房写真を10%透過で重ねる）
- 中央寄せ・白文字: 見出し「暮らしに、窯の温もりを。」
- CTA 2つ: `c-btn--primary`「オンラインショップ」 / `c-btn--ghost-inv`「お問い合わせ」

### S8. フッター `c-footer`（背景: ink・白文字）
- docs/02 §5 の通り

## 4.2 会社案内（mockups/about.html）

1. ページヘッダー `s-pagehead`: porcelain 地、ラベル "ABOUT US" + h1「会社案内」+ パンくず
2. ブランドステートメント: container-narrow、リード文（serif・fs-lg）
3. 沿革 `s-history`: 縦タイムライン（年号 font-en gold / 出来事）
   - 昭和26年 輸出向け陶磁器人形の製作を開始 / （中略可）/ 2023年9月 KM名古屋ドール株式会社に社名変更
4. 製造工程（詳細版）`s-process-full`: 7工程すべてを交互2カラム（画像⇄テキスト）で
5. 会社概要 `s-company`: 定義リスト型テーブル（社名/所在地/電話/代表/設立/事業内容）
6. アクセス: 現行本番サイトと同一地点・店舗情報のGoogleマップ埋め込み + 住所。iframeは遅延読み込み、PC 21:9 / SP 4:3
7. フルワイドCTA（トップの S7 を再利用）

## 4.3 商品一覧（mockups/collection.html）

1. ページヘッダー: h1 = コレクション名 + 商品数
2. **ピックアップバナー `s-collection-banner`**: 一覧最上部。横長カード（画像+「季節のおすすめ」ラベル+商品名+価格+`c-btn--primary`「商品を見る」）。管理画面から商品1点を指定
3. ツールバー: 左=カテゴリタブ（横スクロール可）/ 右=並び替え select（おすすめ/新着/価格）
4. 商品グリッド: PC4列/SP2列。カードは c-card（バッジ対応）
5. ページネーション: 数字+前後矢印（無限スクロール不採用）
6. 0件時: 「該当する商品がありません」+ 全商品へのリンク

## 4.4 商品詳細（mockups/product.html）

- 2カラム（PC: ギャラリー55% + 情報45%、SP: 縦積み）
- ギャラリー: メイン大画像 + サムネイル横並び（クリックで切替）
- 情報カラム:
  1. パンくず（ホーム / カテゴリ / 商品名）
  2. カテゴリ名(label) + 商品名(serif h1) + バッジ
  3. 価格（fs-h2 相当・sans 500）+「税込」+ 送料注記(sm)
  4. 商品説明（3-6行）
  5. バリエーション select（サイズ/色。ある場合のみ）
  6. 数量ステッパー + **「カートに入れる」`c-btn--primary` フル幅** + Shopify動的チェックアウトボタン
  7. アコーディオン: 素材・サイズ詳細 / 配送について / 返品・交換
- **作り手ブロック `s-maker`**: 情報カラム下 or 全幅。工房写真+「瀬戸の窯元が一点ずつ手仕事で」+ 会社案内リンク（EC→コーポレート導線）
- 関連商品: 同コレクション4点（c-card 再利用）
- モバイル: 画面下部に「カートに入れる」固定バー（価格+ボタン）

## 4.5 お知らせ一覧（mockups/news.html）・記事（mockups/news-article.html)

**CMSはShopify標準のブログ機能を使用**（ブログ `news` を作成。管理画面から記事を入稿）。

### 一覧（templates/blog.json）
1. ページヘッダー: ラベル "News" + h1「お知らせ」+ パンくず
2. リスト: container-narrow。トップの S6 と同じ行形式（日付 / タグバッジ / タイトル）
   - バッジはブログ記事の**タグ**で出し分け（お知らせ / 商品情報 / 催事 など）
   - SP ではトップ同様「日付+バッジ／タイトル」の2行構成
3. ページネーション（Shopify paginate、1ページ10件）

### 記事（templates/article.json）
- container-narrow の1カラム。パンくず → 日付+タグバッジ → タイトル(serif h1) → 罫線 → 本文
- 本文は管理画面のリッチテキスト（画像挿入可）。画像は radius-md・16:9 推奨
- 末尾に `c-btn--ghost`「お知らせ一覧へ戻る」
- SNSシェア・コメント機能は使わない（コメントはブログ設定で無効化）

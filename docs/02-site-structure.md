## 3. 主要導線（ユーザーフロー）

### A. 購入導線（最短ルート厳守）
```
トップ → ピックアップ商品カード → 商品詳細 → カート → チェックアウト
（トップから2クリックで商品詳細、3クリックでカート）
```

### B. コーポレート→EC 送客導線（本サイトの肝）
コーポレートコンテンツの各ブロック末尾に必ず EC への「文脈付きリンク」を置く：
- トップ「私たちについて」ブロック → 「会社案内を見る」+「オンラインショップへ」
- トップ「製造工程」ブロック → 「この手仕事から生まれた商品を見る →」(/collections/lace-doll)
- 会社案内ページ末尾 → 「オンラインショップはこちら」フルワイドCTA

### C. EC→コーポレート 信頼補強導線
- 商品詳細ページに「作り手について」ミニブロック（工房写真+一文+会社案内リンク）
  → 初見客の購入不安を歴史・製造背景で解消する

### D. 売り出し商品の露出設計
| 場所 | 仕組み |
|---|---|
| トップ・ヒーロー直下 | 「ピックアップ商品」セクション（手動選定コレクション `featured`、最大4点、大きめカード） |
| 商品一覧の最上部 | ピックアップバナー（1点推し。季節商品差し替え運用） |
| 商品詳細の下部 | 関連商品（同コレクションから4点） |
| 商品カード | 「PICK UP」「NEW」「残りわずか」バッジ（タグ駆動） |

## 4. トップページの情報設計（セクション順序と役割）

| # | セクション | 役割 | 導線 |
|---|---|---|---|
| 1 | ヒーロー（動画/画像 切替可） | ブランドの世界観を3秒で伝える | 主CTA「オンラインショップ」/ 副CTA「私たちについて」 |
| 2 | ピックアップ商品 | 売り出したい商品を最速で見せる | 商品詳細へ |
| 3 | 私たちについて（会社説明ダイジェスト） | 1951年創業・瀬戸焼の信頼 | 会社案内へ |
| 4 | 製造工程ハイライト（7工程を4枚に集約） | 手仕事の価値訴求 | レース人形コレクションへ |
| 5 | カテゴリから探す（6カテゴリ） | 目的買いの受け皿 | 各コレクションへ |
| 6 | お知らせ（最新3件） | 稼働している会社であることの証明 | お知らせ一覧へ |
| 7 | フルワイドCTA | 取りこぼし回収 | ショップ / お問い合わせ |
| 8 | フッター | 会社情報・規約・SNS | — |

順序の意図: **EC（ピックアップ）を先、会社説明をその直後**。
購買意欲のある訪問者を待たせず、初見の訪問者には 3→4 で信頼を積んでから 5 で再度 EC へ落とす。

## 5. フッター（全ページ共通）

- 会社名・住所・電話・ロゴ / 「昭和26年創業・瀬戸焼の窯元」の一文
- サイトマップリンク（3カラム: 会社情報 / オンラインショップ / サポート）
- 特定商取引法に基づく表記 / プライバシーポリシー / 配送・返品について
- 決済アイコン（Shopify標準）
- **SP（600px以下）**: 縦積みにしない。会社情報=全幅 → Company / Online Shop=2カラム並列 → Support（規約系）=全幅・横並び（flex wrap）。縦に間延びさせないこと（スタイルは style.css の 600px メディアクエリが正）
